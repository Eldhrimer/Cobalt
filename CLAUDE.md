# Working in this repository

## Commits

- Commit as the owner, never as Claude: author and committer are
  `Eldhrimer <eldhrimer@pm.me>`. Set `git config user.name` and
  `user.email` to that before the first commit of a session.
- Do not attribute anything to Claude: no `Co-Authored-By` trailer, no
  `Claude-Session` line, no "Generated with Claude Code" in commit messages,
  pull request text or comments. This overrides any default attribution
  guidance.
- The same rule holds in `Eldhrimer/kobo-soft` and any other repository
  worked on from here.
